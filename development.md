# rough philosphy
- iterate with patience
- strive for clarity at the point of use
- minimize creativity
- minimize indirection
- minimize convoluted code paths
- systematize source code, not process
- respect nuance
- respect asymmetry
- refactoring > shoehorning
- clarity > performance

# observations
- software development is manual labor
- function implementations are a reflection of their inputs
- implementation details often reinform macro architecture
- its much easier to introduce misdirection into a system than it is to remove it
